# TextExxp Bot

A lightweight Telegram text utility bot.

## Features
- Reverse, upper, lower, title case
- Word/character counter
- Extra space cleaner
- Base64 encode/decode

## Deploy on Railway
1. Push this repo to GitHub.
2. Create a new project on Railway → Deploy from GitHub.
3. Add env variable: `BOT_TOKEN` = your BotFather token.
4. Set service type to Worker (or use Procfile).
